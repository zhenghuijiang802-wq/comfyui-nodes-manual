ComfyUI 连线心法

先确认数据类型，再决定节点位置

ComfyUI 中的“线”不能随意连接：输出插槽和输入插槽的数据类型必须匹配，其对应的颜色也是一致的。 学习新节点时，重点看三件事：它需要输入什么数据、输出什么结果、以及其关键参数会如何影响画面。

MODEL：大模型，常接采样器
CONDITIONING：正反向提示词条件
LATENT：潜空间，采样前后传递
IMAGE：普通像素图像，用于预览或处理
VAE：负责 IMAGE 与 LATENT 编解码转换
CLIP：把提示词文本转化为模型条件
基础文生图 (Text to Image)
CheckpointLoader → CLIPTextEncode x2 → EmptyLatentImage → KSampler → VAEDecode → SaveImage
图生图 / 局部重绘 (Img2Img / Inpaint)
LoadImage → VAEEncode → KSampler (denoise 0.3-0.7) → VAEDecode
ControlNet 条件控制 (Canny/Pose)
LoadImage → Canny预处理器 → ControlNetApply → KSampler (接正向)
双采样高清放大 (Hi-Res Fix)
KSampler 1 → LatentUpscale → KSampler 2 (denoise 0.3-0.5) → VAEDecode
