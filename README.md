# 🚀 ComfyUI 智能说明书 & AI 学习助手 (ComfyUI Nodes Manual & AI Assistant)

一个专为 ComfyUI 学习者和创作者打造的**现代化、极速、无痛离线版智能节点说明书**。通过极低的学习门槛和贴心的 AI 提问辅助，帮助你快速掌握 ComfyUI 中成百上千个复杂节点的连接规则与核心技巧！

---

## 🌟 核心亮点 (Key Features)

* **⚡ 离线即用，双击开箱**
  * 纯前端实现，零依赖，无任何繁琐的环境配置。下载/克隆仓库后，**双击 `index.html` 即可在浏览器中瞬间启动**！
* **🔍 全文智能检索与中英对照**
  * 支持输入节点英文 Class ID、中文展示名、节点描述、功能分组、输入输出插槽类型等全方位搜索。即使只记得部分关键词，也能一秒定位。
* **📂 多维智能导航与功能地图**
  * **树状分类树**：清晰呈现官方核心包及主流自定义插件（LoRA、ControlNet、AnimateDiff 等）的节点层级。
  * **功能分组地图**：一目了然地解构采样（Sampling）、模型加载、图像处理等核心功能模块。
  * **术语词汇表**：为初学者量身定制的常用图像生成及 ComfyUI 专业词汇库。
* **📋 一键批量集成 ComfyUI**
  * 勾选你需要的节点，点击底部的 **“一键复制”**，在你的 ComfyUI 界面中直接 `Ctrl + V`，即可瞬间批量导入所有勾选的节点，省去在 ComfyUI 搜索框中一个个查找的烦恼！
* **📝 个人专属学习笔记**
  * 针对每个节点，随时记录自己的踩坑经历、连线技巧或心得。支持浏览器 `localStorage` 自动保存，数据绝不丢失。
* **🤖 智能 AI 提示词生成器**
  * 遇到不懂的节点？点击节点上的 AI 提问按钮，一键生成包含该节点所有输入输出类型及描述的标准化提问提示词，直接粘贴给 ChatGPT / Gemini，让 AI 成为你专属的 ComfyUI 导师！

## 📂 项目结构 (Repository Structure)

项目将庞大的节点数据库与核心逻辑进行了**解耦设计**，文件结构极其清晰，不仅极易二次开发，也对开源社区的协同修改非常友好：

```bash
comfyui-nodes-manual/
├── index.html         # 现代暗黑美学玻璃拟态前端主页面
├── style.css          # 全局现代 UI 样式系统（包含精心调配的插槽配色）
├── app.js             # 搜索、笔记、剪贴板交互等前端核心逻辑
├── data/
│   ├── nodes_data.js  # 前端专用的轻量级节点数据库（适配本地 file:// 直接双击加载）
│   └── nodes_data.json# 标准 JSON 格式节点数据（方便第三方 API、爬虫及工具链调用）
├── LICENSE            # 开源许可证 (MIT License)
├── .gitignore         # Git 忽略配置
└── README.md          # 本项目的使用与贡献说明书
```

## 🚀 快速上手 (Quick Start)

### 方法 1：直接双击运行 (推荐，零门槛)
1. 点击右上角 **Code** -> **Download ZIP** 下载本项目压缩包。
2. 解压到本地任意目录。
3. 双击运行 **`index.html`**，即可开始你的 ComfyUI 节点学习探索之旅！

### 方法 2：使用 Git 克隆
如果你是开发者或 Git 用户：
```bash
# 1. 克隆本项目
git clone https://github.com/你的GitHub用户名/comfyui-nodes-manual.git

# 2. 进入项目文件夹
cd comfyui-nodes-manual

# 3. 直接双击 index.html 运行，或者使用本地静态服务启动
```

## 🤝 参与贡献 (Contributing)

本项目的核心目标是帮助广大 ComfyUI 爱好者更好地学习和上手。如果你发现某个节点的中文翻译不够精准，或者发现了漏掉的主流插件节点，非常欢迎你参与贡献！

1. Fork 本项目。
2. 在 `data/nodes_data.json` 中找到或添加对应节点的定义，补充说明、输入输出或中文翻译。
3. 提交 Pull Request，我们会第一时间合并，让更多学习 ComfyUI 的小伙伴受益！
